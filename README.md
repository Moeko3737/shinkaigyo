# 深海魚にはかなわない（仮）｜漫画企画書・詳細版

お仕事ラブコメディの漫画企画書ページです。

## ファイル構成

```
index.html    企画書ページ本体
images/       ページで使っている画像
```

## 公開のしかた（GitHub Pages）

1. このフォルダの中身をリポジトリにアップロードする
2. リポジトリの Settings → Pages を開く
3. Source を「Deploy from a branch」、Branch を `main` ／ `/ (root)` にして保存
4. 数分後に表示されるURLで企画書が見られます

※ 掲載イラストは作品イメージを伝えるためのAI生成ビジュアルです。
